# NexusRPG — Roadmap: лор магии → игровые системы

> **Общий порядок разработки всего мира — в [LORE_MASTER_ROADMAP.md](LORE_MASTER_ROADMAP.md), а конкретные незакрытые вопросы — в [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md).** Этот файл остаётся **тематическим backlog по магии и будущим игровым системам**, а не командой сейчас реализовывать численную магию E3/G1. По принятому процессу WB-066 перед миростроением общества достаточно закрыть **минимальные физические условия безопасного входа/выхода FTL**, не добиваясь полной инженерной спецификации B1/D1. Генеральная очередность — рабочий план, **не каноническая история мира**.

> **Приоритет согласован 22.10.2026:** сперва технический аудит и очистка репозитория, потом окончательное оформление ЛОРа. Этапы игровой реализации (P1–P5 ниже) **отложены до завершения и утверждения ЛОРа**, а не являются текущей командой на написание новых механик/квестовых хуков.

**Редакция:** 2026-10-22. Это тематическая дорожная карта лора и последующей интеграции, **не** оценка готовности репозитория и не обещание выполненной реализации.

## P0 — зафиксировать непротиворечивые правила (дизайн)

- [x] Определить редкость одарённости: 0,5–2%.
- [x] Выбрать вероятностную наследственность.
- [x] Выбрать детскую диагностику как норму.
- [x] Ограничить область искусственных модификаций преимущественно военными/экспериментальными программами.
- [x] Не унифицировать социальное положение магов между государствами.
- [x] Выбрать базовую онтологию: **гибридная магия — объективна и измерима, но фундаментально не до конца объяснена** (WB-024).
- [x] Выбрать смешанную энергетическую модель E3: магический ресурс и физический обмен (WB-026).
- [ ] Утвердить физические законы, ограничения и конкретную цену применения: источник ресурса, скорость доступа, энергобаланс, потери, противодействие.
- [x] Выбрать область воздействия: физические состояния и отдельные взаимодействия, вариант B (WB-027).
- [x] Зафиксировать редкую, сложную, ограниченную прямую гравитационную магию (WB-030).
- [x] Утвердить физическую модель гравитации G1: локальная модуляция существующего взаимодействия (WB-031).
- [x] Утвердить объектную привязку G1/B: взаимодействие существующих физических объектов, включая глубокий космос, без обязательного крупного якоря (WB-033).
- [ ] Согласовать численные условия сопряжения (масса, геометрия, число объектов, дальность), модель обмена энергией и импульсом E3 и методы адресации.
- [ ] Определить, какие эффекты в глубоком космосе реализуемы на практике и каковы их цена и риски.
- [ ] Согласовать роль гравитационной магии в корабельной искусственной тяжести, транспорте и обороне без слома экономики.
- [ ] Согласовать конкретные классы, запреты, стоимость, дальность и масштаб.
- [ ] Установить независимые параметры природной одарённости и методы измерения.

**Критерий:** таблица ограничений и 10 проверяемых примеров техник без противоречий.

## P1 — спецификации магии и CAD

- [ ] Описать JSON-схему профиля одарённости, навыка, техники, устройства CAD и лицензии.
- [ ] Развести врождённый потенциал / изученную теорию / практический контроль / оборудование.
- [ ] Спроектировать активацию и подавление: блокировки, ошибки, тайминги, взаимодействие с обычной физикой.
- [ ] Протестировать начального ученика, профессионального инженера, военного и неодарённого персонажа.
- [ ] Разработать баланс без универсального «супермага».

**Критерий:** игровые действия с предсказуемыми исходами; ИИ не может вводить новые эффекты вне разрешённых правил.

## P2 — вертикальный срез академии

- [ ] Создать одну модель академии без утверждения её названия/места как галактического канона.
- [ ] Вступительный отбор, стипендии, календарь, предметы, клубы, студсовет.
- [ ] Четыре предлагаемых направления обучения + возможность смены.
- [ ] Отдельные оценки: теория, практика, проекты, отношения.
- [ ] Учебная неделя, экзамен, клубный проект, конкуренция NPC и переход к следующему периоду.
- [ ] Пропуск недели/семестра без самовольных критических решений от лица игрока.

**Критерий:** один полностью воспроизводимый учебный семестр с сохранением и загрузкой.

## P3 — кланы и государства

- [ ] Система клана: члены, ветви, активы, влияние, интересы, наследование.
- [ ] Региональные законы по диагностике, CAD, лицензиям и модификациям.
- [ ] События: стипендия, контракт на исследование, конфликт интересов, миграция специалиста.
- [ ] Различия между системой гражданской интеграции, строгого контроля, корпораций и периферии.

**Критерий:** организация самостоятельно реагирует на событие и изменения остаются в мире после ухода игрока.

## P4 — военное применение

- [ ] Военно-технический баланс, подготовка специалистов, обычные подразделения.
- [ ] Разграничение адресного CAD-подавления, зональных помех, контрмагии.
- [ ] Влияние на мехи и корабли: расходы, ресурсы, ограничения и эффективность.
- [ ] Политика экспериментальных модификаций и последствия для NPC.

## P5 — внедрение в NexusRPG1

- [ ] Сверить актуальную архитектуру репозитория и уже имеющиеся механики, **не предполагать их наличие по README**.
- [ ] Выбрать место для JSON/БД моделей, не создавать второй независимый источник истины.
- [ ] Отделить детерминированные правила от прозы AI GM.
- [ ] Создать миграции/валидацию для сохранений, если меняется модель персонажа.
- [ ] Покрыть тестами создание персонажа без магии и с магией; обучение; работу CAD; анти-CAD; экзамен; таймскип; сохранение/загрузку.
- [ ] Проверить E2E: 14-летний ученик → поступление → занятия → проект → экзамен → изменение отношений/состояния.
- [ ] Отдельно проверить, что игрок может **не поступать** в академию и симуляция мира продолжает работать.

**Критерий:** тесты подтверждают состояние и воспроизводимость; после этого функциональность можно помечать реализованной.
