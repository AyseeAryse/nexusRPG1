## Правила работы с лором

1. **Принято** — пользователь явно выбрал или подтвердил решение; не менять молча.
2. **Проект / рабочая гипотеза** — разработано в беседе, но не окончательно утверждено.
3. **Открыто** — требует отдельного решения.
4. **Не канон** — экспериментальные NPC, академии и цифры, приведённые для объяснения системы.
5. **Шесть референсов как единая система (WB-002):** The Expanse, Cyberpunk 2077, Legend of the Galactic Heroes, Gundam, Metal Gear и Mahouka. Не копировать названия, персонажей, устройства государств, магию или сюжет; проверять последствия каждой важной новинки для остальных сфер.
6. Сюжет и образование — опциональные пути; вся вселенная развивается независимо от игрока.
7. При изменении **канона** обновить WORLD_BIBLE, DECISIONS, соответствующий профиль и OPEN_QUESTIONS в одном PR. Для одной только редакционной/процессной корректировки не придумывать новые факты мира.
8. **В начале новой крупной темы:** сверить актуальные инструкции ChatGPT-проекта Nexus, решения пользователя, документы и, когда обсуждаем реализацию, исходный код. Инструкции проекта — регламент разработки; они не объявлены автоматически сохранённым дословно файлом в GitHub.
9. **Не застревать на деталях одной технологии:** закрывать только ограничения, без которых не объяснить следующий социальный, политический или игровой блок; прочее фиксировать в OPEN_QUESTIONS с приоритетом и ссылками.
10. **AI GM не источник физики и игрового состояния:** он отвечает за описание, намерения и диалоги; изменения ресурсов/проверок/состояния проходят через проверяемые правила и валидируемые операции движка.

> Важно: сохранение документации в GitHub происходит только при внесении и слиянии изменений в репозиторий. Разговор сам по себе не обновляет файлы автоматически.
