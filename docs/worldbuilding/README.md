# NexusRPG — Worldbuilding index

**Редакция:** 0.8 (22.10.2026)  
**Рабочий репозиторий:** `AyseeAryse/nexusRPG1`  
**Статус:** документация концепции, не свидетельство реализации в коде.

Этот каталог — долговременный источник решений о мире NexusRPG. Не путать его с программной дорожной картой или описанием готовых игровых функций.

## Документы

- [WORLD_BIBLE.md](WORLD_BIBLE.md) — согласованные основы и прорабатываемые институты мира.
- [DECISIONS.md](DECISIONS.md) — журнал принятых, предложенных, отложенных решений.
- [ROADMAP.md](ROADMAP.md) — порядок дальнейшей проработки и реализации в игре.

## Правила работы с лором

1. **Принято** — пользователь явно выбрал или подтвердил решение; не менять молча.
2. **Проект / рабочая гипотеза** — разработано в беседе, но не окончательно утверждено.
3. **Открыто** — требует отдельного решения.
4. **Не канон** — экспериментальные NPC, академии и цифры, приведённые для объяснения системы.
5. Не переносить названия, персонажей, кланы и механику Mahouka, Expanse, Gundam, Cyberpunk или Metal Gear буквально: это референсы, NexusRPG — самостоятельный мир.
6. Сюжет и образование — опциональные пути; вся вселенная развивается независимо от игрока.
7. При изменении лора актуализировать WORLD_BIBLE и DECISIONS в одном PR.

> Важно: сохранение документации в GitHub происходит только при внесении и слиянии изменений в репозиторий. Разговор сам по себе не обновляет файлы автоматически.
