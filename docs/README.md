## Статусы

**В документации** = концепция описана, но механизм может отсутствовать в коде.

**Подтверждено тестами** = протестировано только конкретное поведение.

**Реализовано** = есть исполняемая реализация в активном пути `src/`, не только декларация в JSON или README.

Сначала технический аудит и стабилизация, затем возвращение к ЛОРу. **Новые игровые механики, квестовые хуки и глубинная симуляция разрабатываются после завершения и утверждения ЛОРа.**
