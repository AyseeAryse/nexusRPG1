# Дорожная карта NexusRPG

**Текущая стадия:** alpha / прототип.  
**Цель ближайшего цикла:** получить воспроизводимый запуск и доказать работоспособность базового игрового цикла прежде, чем расширять набор функций.

Статусы отражают план работ, а не заявления о завершённой реализации. Пункт считается завершённым только после выполнения критериев приёмки и прохождения автоматических проверок.

## P0 — Чистая и воспроизводимая база

- [x] Создать отдельный чистый рабочий репозиторий nexusRPG1.
- [x] Удалить случайный файл RPG-main с фрагментом diff.
- [x] Синхронизировать README со структурой и командами запуска текущей ветки.
- [x] Включить CI для чистой установки зависимостей, компиляции и тестов.
- [x] Устранить тесты, которые считают HTTP 4xx/5xx допустимым результатом нормального маршрута.
- [ ] Зафиксировать канонические точки входа и правила импорта.

**Критерии приёмки:** чистый checkout устанавливает зависимости, импортирует ключевые модули и выполняет тестовый набор; ожидаемые ошибки не маскируются.

## После v0.1 — расширение продукта

Функции ниже пока не должны опережать стабилизацию ядра:

- Редактор пользовательских кампаний.
- Расширение памяти и управления контекстом ИИ.
- Генерация изображений локаций и озвучивание NPC.
- Мобильная адаптация интерфейса.
- Мультиплеер и синхронизация состояния.
- Поддержка модификаций и внешних интеграций.

Для каждой будущей функции следует создать GitHub Issue с областью работ, зависимостями, критериями приёмки и отдельными тестами. Не следует назначать версии и сроки до оценки технических зависимостей.

## Процесс работы

1. Одна логическая задача — один Issue и небольшой PR.
2. В PR указывать причину изменения, затронутые системы, тесты и известные ограничения.
3. Не сливать архитектурный рефакторинг одновременно с изменением игровых правил без необходимости.
4. Не отмечать пункт завершённым только потому, что добавлен файл или класс.
5. После каждого изменения проверять CI и короткий ручной сценарий, если затронут интерфейс или запуск.
