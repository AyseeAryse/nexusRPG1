# 🌌 NexusRPG

**Космическая RPG с ИИ-гейм-мастером**

NexusRPG — экспериментальная настольная RPG в веб-интерфейсе. Игрок управляет персонажем, а ИИ помогает вести повествование в мире с квестами, фракциями, боевыми столкновениями, экономикой и процедурной генерацией.

> **Статус:** активный прототип / alpha. Наличие системы в исходном коде не означает, что она полностью реализована или прошла интеграционное тестирование. Для актуальных приоритетов см. [ROADMAP.md](ROADMAP.md).

## Что есть в проекте

- Создание персонажа и данные происхождения, биографии и специализаций.
- Игровое состояние, проверки навыков и пошаговая боевая система.
- Веб-интерфейс на Flask и API для взаимодействия с игровыми системами.
- Интеграция с ИИ через локальные и совместимые API-бэкенды.
- Системы квестов, NPC, спутников, фракций, торговли, крафта, кораблей, расследований и взлома.
- JSON-база игровых правил, контента и генераторов.

Эти возможности находятся в разработке. Перед выпуском необходима проверка полного игрового цикла и отдельных механик.

## Структура репозитория

```text
nexusRPG1/
├── src/
│   ├── core/       # Игровое состояние и движок
│   ├── ai/         # AI-коннектор и база знаний
│   ├── content/    # Данные и совместимость со старыми наборами контента
│   ├── systems/    # Боевая, квестовая и другие игровые системы
│   ├── world/      # Галактика, NPC и симуляция мира
│   └── server/     # Flask-приложение и API
├── game_data/      # JSON-контент; старые варианты могут быть в archive/
├── static/         # CSS и JavaScript веб-клиента
├── templates/      # HTML-шаблоны
├── tests/          # Автоматические тесты
├── docs/           # Архитектура, тестирование и руководство по контенту
├── launcher.py     # Интерактивный лаунчер
├── config.py       # Совместимый корневой модуль конфигурации
├── requirements.txt
└── ROADMAP.md
```

Основная модульная реализация находится в `src/`. В корне пока остаются некоторые исторические/совместимые модули; их окончательное устранение отслеживается в roadmap.

## Требования

- Python 3.11 или новее.
- Для локального ИИ — отдельно установленный и настроенный Ollama либо совместимый локальный API.
- Для облачного ИИ — API-ключ и поддерживаемый endpoint.
- Доступ к интернету требуется для установки Python-зависимостей и облачных моделей; локальный режим зависит от настройки выбранного бэкенда.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/AyseeAryse/nexusRPG1.git
cd nexusRPG1
```

### 2. Создать виртуальное окружение и установить зависимости

Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Linux/macOS:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Настроить ИИ

Скопируйте `.env.example` в `.env` и задайте необходимые параметры для выбранного бэкенда. Не добавляйте реальные API-ключи в Git.

Для локального бэкенда установите и запустите Ollama или LM Studio отдельно, загрузите совместимую модель и проверьте адрес API. Для облачного доступа настройте endpoint и ключ в соответствии с переменными из `.env.example`.

## Запуск

Рекомендуемый вариант:

```bash
python launcher.py
```

Альтернативный запуск Flask-приложения из корня репозитория:

```bash
python -m src.server.app
```

При стандартных настройках сервер использует порт `8080`; фактический адрес и порт могут быть изменены переменными окружения `HOST` и `PORT`. После запуска откройте указанный адрес в браузере, например `http://127.0.0.1:8080`.

Не публикуйте сервер в интернете без отдельной проверки авторизации, сетевого доступа, секретов и конфигурации production-сервера.

## Тесты и проверки

Запуск тестов:

```bash
python -m pytest tests/ -q
```

Проверка синтаксиса:

```bash
python -m compileall -q src tests
```

Тесты не должны требовать реального облачного API-ключа или работающего сервера ИИ. Результат текущего прогона следует проверять в GitHub Actions и локально после изменения кода. Наличие теста само по себе не подтверждает, что все ветви сценария игры проверены.

Подробнее: [docs/TESTING.md](docs/TESTING.md).

## Разработка

- Перед крупной задачей сверяйтесь с [ROADMAP.md](ROADMAP.md).
- Изменения вносите небольшими PR с описанием причины, поведения до/после и проведённых проверок.
- Новые игровые данные добавляйте в соответствующие JSON-файлы в `game_data/`; проверяйте, что загрузчик действительно выбирает нужный файл.
- Не коммитьте `.env`, сохранения, виртуальное окружение, `__pycache__`, сборочные бинарные файлы и секреты.
